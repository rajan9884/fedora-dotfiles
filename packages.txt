# fedora-dotfile — package set for Fedora (dnf5).
#
# Every entry was verified present in an enabled Fedora 44 x86_64
# repository. Void-only / renamed packages were dropped or remapped;
# README.md documents the full mapping.
#
# This file is dnf-only and intentionally contains nothing that needs a
# third-party repository. install.sh handles those separately, because
# they need a different trust model (COPR repos / upstream releases):
#
#   swayfx      <- COPR mochaa/swayfx        (compositor, sway fork)
#   swayosd     <- COPR erikreider/swayosd   (volume/brightness OSD)
#   starship    <- upstream GitHub release   (shell prompt)
#   hyprpicker  <- COPR nett00n/hyprland     (Wayland colour picker)
#
# yazi is intentionally omitted (unused).
#
# Pure Wayland: no Xorg server, no XWayland, no X11 client packages.
# The compositor runs with `xwayland disable`, so nothing here pulls one in.

# ── Compositor ──────────────────────────────────────────────────────

# ── Audio: one PipeWire session, socket-activated by systemd ────────
# Void booted pipewire by hand from the compositor config. Fedora spawns
# pipewire and pipewire-pulse from systemd user sockets, so the config no
# longer starts the daemon itself (a manual start fights the socket unit).

rtkit
