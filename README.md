# fedora-dotfile

Sway-based Wayland desktop configuration for Fedora (x86_64).
The repository holds every managed dotfile; `install.sh` reproduces the full
setup — packages, services, symlinks, login manager, fonts — on a fresh
Fedora installation.

Pure Wayland: no Xorg server, no XWayland, no X11 client packages. The
compositor runs with `xwayland disable`.

## Requirements

- Fedora x86_64 (tested on 44), base install with network access
- A non-root user with `sudo` rights (`usermod -aG wheel <user>`)
- Git: `sudo dnf install -y git` (the installer covers everything else)

## Quick start

```sh
git clone https://github.com/rajan9884/fedora-dotfile.git ~/fedora-dotfile
cd ~/fedora-dotfile
./install.sh
```

Partial runs:

```sh
./install.sh --packages-only   # dnf packages + services only
./install.sh --links-only      # (re)create symlinks only
./install.sh --no-fonts        # skip the Nerd Font download
./install.sh --no-wallpapers   # skip the wallpaper collection download
./install.sh --no-external     # skip COPR repos + out-of-tree binaries
```

Reboot after the first run so group membership (`video`, `input`, `render`)
and the greetd login manager take effect. Log in through tuigreet, select
the Sway session, and the desktop starts.

## What the installer does

1. **Third-party repos** — enables two COPRs (skipped with `--no-external`):
   - `mochaa/swayfx` — the swayfx compositor (blur, shadows, rounded corners)
   - `erikreider/swayosd` — volume/brightness OSD (`swayosd-server`)
   - `nett00n/hyprland` — the `hyprpicker` Wayland colour picker
2. **Packages** — installs every entry in `packages.txt` via `dnf5`
   (compositor, terminal, launcher, bar, audio, portals, CLI tools, fonts,
   toolchain). Swaps `sway`→`swayfx` and `tuned-ppd`→`power-profiles-daemon`
   when the stock packages are present, since they conflict.
3. **Out-of-tree binaries** (skipped with `--no-external`) —
   `starship` from its upstream GitHub release (sha256-verified) into
   `~/.local/bin`.
4. **Services** — enables `NetworkManager`, `bluetooth`, `chronyd`,
   `crond`, `greetd`, `iwd`, `power-profiles-daemon`, `polkit` via
   `systemctl`. Audio needs no service step: PipeWire, WirePlumber and
   pipewire-pulse are socket-activated by systemd user units.
5. **Login manager** — creates the `_greeter` system user (Fedora's greetd
   package ships none), writes `/etc/greetd/config.toml` (tuigreet on VT7
   with the Sway Wayland session), disables `sddm` when it conflicts, and
   ensures the `wheel` sudoers entry.
6. **Groups** — adds the user to `wheel`, `video`, `input`, `render`.
7. **Dotfiles** — symlinks each tracked directory into `~/.config`,
   shell startup files into `$HOME`, and every script in `bin/` into
   `~/.local/bin`. Re-runs never write into the repo itself.
   Pre-existing files move to `~/.config-backup-fedora-<timestamp>/`.
8. **Shell** — adds zsh to `/etc/shells` and sets it as the login shell;
   zsh starts Sway automatically on TTY1 via `shell/zprofile`.
9. **Fonts** — downloads JetBrainsMono Nerd Font and
   NerdFontsSymbolsOnly into `~/.local/share/fonts`.
10. **Wallpapers** — clones the
    [wallpapers](https://github.com/rajan9884/wallpapers) collection,
    flattens every image into `~/.local/share/wallpapers`, and generates
    a fallback wallpaper if the clone fails, so sway always has a
    background.
11. **First boot** — creates empty `sway/colors` and `sway/wallpaper`
    (matugen fills them on the first switch) so sway never aborts on a
    missing `include`.

The script is idempotent; re-running it repairs anything missing.

| `nvim/` | `~/.config/nvim` | Neovim configuration |
| `swaync/` | `~/.config/swaync` | Notification center |
| `matugen/` | `~/.config/matugen` | Material-you color templates (source of truth) |
| `xdg-desktop-portal/` | `~/.config/xdg-desktop-portal` | Portal backend preferences |

Generated files (`sway/colors`, `waybar/colors.css`, `foot/colors.ini`,
wallpaper pointer, etc.) are git-ignored; the templates under
`matugen/templates/` are the versioned source they are rendered from.

## Theming pipeline

Wallpaper drives the theme. `sway/scripts/sway-wall.sh <image>` records
the wallpaper, stages the lock-screen background, and runs matugen, which
recolors Waybar, Rofi, Foot, Sway, SwayNC, SwayOSD, GTK, and Starship in
one pass. Related helpers: `fedora-wallpaper-picker`, `random-wall.sh`,
`init-wallpaper.sh` (restores the last wallpaper at login).

Only the **noro** Waybar preset is shipped (`waybar/themes/noro/`, linked
as `waybar/config.jsonc` + `waybar/style.css` so the bar works on first
boot with no selection step).
